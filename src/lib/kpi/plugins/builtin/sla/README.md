# SLA Domain

Plugins in this domain measure Service Level Agreement compliance and target adherence.

## Metrics

- **SLA Compliance** - Percentage of issues meeting SLA targets
- **SLA by Priority** - Compliance broken down by priority level
- **SLA by Status** - Compliance by current status
- **SLA Breaches** - Count and details of SLA violations

## Common Use Cases

- Tracking contractual obligations
- Identifying systematic SLA issues
- Measuring service quality improvements
- Reporting on service guarantees

## Data Requirements

- SLA target definitions (hours per priority)
- Issue creation timestamps
- Issue resolution timestamps
- Current status for ongoing violations
- Comment timestamps (if SLA based on response time)

## Typical Dimensions

- By priority level
- By issue type
- By project/team
- By time period
- Breach vs compliant

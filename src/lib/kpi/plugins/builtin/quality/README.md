# Quality Domain

Plugins in this domain measure code quality, defect rates, and rework metrics.

## Metrics

- **Bug Rate** - Percentage of issues that are bugs
- **Reassignment Rate** - Frequency of issue reassignment
- **Reopen Rate** - Percentage of resolved issues that are reopened
- **Resolution Quality** - First-time fix rate

## Common Use Cases

- Identifying process issues requiring rework
- Measuring code quality trends
- Tracking technical debt indicators
- Evaluating team performance consistency

## Data Requirements

- Issue type classification
- Assignment history
- Resolution status history
- Reopen events

## Typical Dimensions

- By issue type
- By priority
- By assignee/team
- By time period
- By project/component

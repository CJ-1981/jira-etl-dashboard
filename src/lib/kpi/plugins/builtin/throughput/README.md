# Throughput Domain

Plugins in this domain measure work completion rates and velocity metrics.

## Metrics

- **Throughput** - Number of issues resolved per time period
- **Resolution Rate** - Percentage of issues resolved
- **Velocity** - Story points or complexity units completed
- **Work Added** - New issues created per time period

## Common Use Cases

- Tracking team capacity and velocity
- Forecasting completion dates
- Identifying workload trends
- Measuring process stability

## Data Requirements

- Issue creation dates
- Issue resolution dates
- Issue complexity/size estimates (optional)
- Time period boundaries

## Typical Dimensions

- By time period (daily, weekly, monthly)
- By priority
- By issue type
- By assignee/team
- By project/component

# Assignee Domain

Plugins in this domain measure individual and team performance metrics.

## Metrics

- **Open Tickets by Assignee** - Current workload distribution
- **Tickets by Priority** - Breakdown of work by priority level
- **Individual Velocity** - Completion rate per assignee
- **Work Distribution** - Balance of workload across team

## Common Use Cases

- Monitoring workload balance
- Identifying over/under-utilized resources
- Tracking individual performance trends
- Capacity planning and resource allocation

## Data Requirements

- Current assignee for each issue
- Issue status
- Issue priority
- Assignment history
- Resolution timestamps

## Typical Dimensions

- By assignee
- By team
- By priority
- By issue type
- By time period

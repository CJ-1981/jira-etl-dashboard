# Processing Time Domain

Plugins in this domain measure time-based metrics related to issue processing and response times.

## Metrics

- **Average Processing Hours** - Mean time from creation to resolution
- **Median Processing Hours** - Median time from creation to resolution
- **Time in Status** - Time spent in each workflow status
- **First Response Time** - Time to first comment or assignment

## Common Use Cases

- Tracking team responsiveness
- Identifying bottlenecks in workflow
- Measuring SLA compliance for response times
- Analyzing process efficiency over time

## Data Requirements

- Issue creation timestamp
- Issue resolution timestamp (if resolved)
- Status transition history
- Comment/assignment timestamps

## Typical Dimensions

- By priority
- By assignee
- By issue type
- By project/component

# Electron App Icons

Place your app icons here:

- **icon.png** - Main app icon (512x512px recommended)
- **icon.ico** - Windows icon (256x256px recommended)  
- **icon.icns** - macOS icon (1024x1024px recommended)

## For Development

You can use online tools to generate Electron icons:
- https://electronjs.org/docs/tutorial/tutorial-icons
- https://icoconvert.com/

For now, the app will use default Electron icons.
